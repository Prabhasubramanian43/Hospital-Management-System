## Run Project

### Backend

Open terminal:

cd server

Install packages:

npm install

Start server:

npm run dev

Backend:

http://localhost:5000

### Frontend

Open another terminal:

cd client

Install packages:

npm install

Start React:

npm run dev

Frontend:

http://localhost:5173

## About

Simple hospital management system using React.js, Node.js, Express.js and MongoDB.

Users can register and login, view doctors, book appointments and manage their appointments.
